# Leoni Schunk Monitoring System - Simple Guide

Welcome! This app helps you monitor production machines in real-time. Here's everything you need to know, in simple words.

---

## 🤔 What is this app for?

This app lets you:
- **Watch machines work** in real-time (like a security camera for your production line)
- **See if a machine has a problem** (it will turn red and send an alert)
- **Track how many parts are made** each shift
- **Get maintenance alerts** when something breaks
- **Look at past data** to see what happened before

---

## 🎨 What the colors mean

Each machine has a color that tells you its status:

- 🟢 **Green**: Machine is working perfectly!
- 🔴 **Red**: There's an error - the machine needs help!
- ⚪ **Gray**: Machine is resting or not working right now.

---

## 📱 How to use the app

### 1. Log in or Sign up
- First, you need to make an account or log in
- Ask your manager for the admin email if you need special permissions

### 2. Add a Machine (Poste)
- Click the big **+** button
- Type a name for the machine (like "Poste 1" or "Cutting Machine")
- Upload an Excel file with the machine's data
- Click "Save"

### 3. Watch the Machines
- The home page shows all your machines
- Click on any machine to see more details
- You can pause/restart the simulation if you need to

### 4. Maintenance Alerts
- If a machine has an error, it will show up in the "Maintenance" section
- You can "claim" an alert to say you're working on it
- When you fix it, mark it as "fixed"

---

## 📊 What data do you need?

The app reads Excel files with these columns:
- **Date**: The date (like 15/05/2026)
- **Time**: The time (like 14:30)
- **Splice**: The part ID or number
- **Error-Text**: If there's an error, write it here (leave blank if everything is okay)

Don't worry if your columns have different names - the app will try to figure it out!

## 📝 Quick Tips

- **Shifts**: The app tracks 3 shifts:
  - Shift 1: 06:00 - 14:30
  - Shift 2: 14:30 - 23:00
  - Shift 3: 23:00 - 06:00
- **Export Data**: You can download Excel files of past data from any machine's dashboard
- **Dark/Light Mode**: Click the moon/sun icon to switch between dark and light themes
